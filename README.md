# Week 4: JavaScript Fundamentals

## About This Project

This project is part of my IYF Weekend Academy Season 12 coursework. It demonstrates my practice with JavaScript fundamentals, including variables, data types, operators, functions, conditional statements, arrays, objects, and array methods.

## Projects

- **Calculator:** Performs addition, subtraction, multiplication, division, modulo, and exponentiation. It also handles division by zero.
- **Student Grade Tracker:** Stores student records, calculates student and subject averages, assigns letter grades, identifies the top student and struggling students, and generates report cards.
- **Daily Challenges:** Five separate JavaScript exercises covering FizzBuzz, reversing a string, finding the largest number, removing duplicates, and checking palindromes.

## What I Learned

- I learned to use `const` and `let` to declare variables instead of `var`.
- I learned that `===` checks both value and type, unlike loose equality (`==`).
- I practiced function declarations and arrow functions.
- I used template literals to create readable strings.
- I practiced array methods such as `map()`, `filter()`, `reduce()`, and `find()`.
- I learned how arrays and objects can store and organize student information.
- I practiced testing JavaScript files with Node.js and viewing browser console output.

## Technologies Used

- HTML5
- JavaScript
- Node.js
- Git and GitHub

## How to Run

1. Clone or download this repository.
2. Open the project folder in a terminal.
3. Run the calculator and JavaScript practice code with `node main.js`.
4. Run the grade tracker with `node grade-tracker.js`.
5. Run individual daily challenges, for example `node daily-challenges/fizzbuzz.js`.
6. Open `index.html` in a browser and press F12 to view console output.
